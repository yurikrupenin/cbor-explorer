# cbx: CBOR Explorer

A TUI application for inspecting CBOR (Concise Binary Object Representation) files, built with Rust and Ratatui.

## Installation

Pre-built binaries for Linux (.deb), Windows and macOS are available in `Releases`.

### Build from source

```bash
cargo build --release
./target/release/cbx <file.cbor>
```

## Usage

```bash
cbx <FILE>
```
